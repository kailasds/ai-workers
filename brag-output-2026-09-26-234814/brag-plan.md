# /brag plan — TCS AI Worker Platform, full product tour (~60s)

User direction: go through the entire project and explain the whole product in about a minute (longer than the usual 15–25s on purpose).

## Rubric
- **What is it:** A platform for composing AI Workers that do real modernization work (TIBCO BusinessWorks → Spring Boot), shipping them to customers, and governing what they learn so only evidence-backed knowledge is shared.
- **Who for:** TCS platform operators and modernization teams running fleets of AI Workers.
- **What sets it apart:** Workers are composed as one governed package (Intent, Brain, Definition of Done, Autonomy); every run is checked against its Definition of Done; learning becomes shared knowledge only after corroboration and a Sentinel decision; maturity (Silver → Gold → Platinum) is earned from evidence.
- **Most impressive real claims:** "JMS acknowledgement mode CLIENT_ACKNOWLEDGE maps to Spring Boot's manual-acknowledgement container mode" — 3 independent Workers, 6 runs, 0 contradictions → certified. DoD evidence: 143 recorded checks across 5 criteria.
- **Visual hook:** Four short lines — "Build AI Workers. / Run them. / Let them learn. / Decide what becomes trusted." — each lighting up the matching items in the app's real sidebar.
- **Real UI shown:** Every chapter is a real screen: Compose (type → identity → brain assembly → DoD → autonomy → Worker Package → build), Packaging, Customer delivery, Registry + "Why Gold?", Dashboard DoD evidence, Learning graph trace, Sentinel review → Accept, Knowledge catalog → provenance.
- **Tone:** `polished` with `app-store` chapter structure — calm, clear, feature-by-feature.
- **Share caption:** "A one-minute tour of the TCS AI Worker Platform: compose a Worker, ship it, watch it learn, and decide what becomes trusted."

## Structure
Hook → reveal → 8 chapters in lifecycle order (build → ship → run → learn → govern → reuse) → loop outro. Each chapter: eyebrow with the section's real nav icon + one caption, the real screen in a stage, a cursor doing the real action. A chapter rail at the bottom shows where we are.
